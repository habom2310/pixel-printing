# Agent instructions

To add pixel-printing to a website, follow [skills/pixel-printing/SKILL.md](skills/pixel-printing/SKILL.md).
To change the library itself, edit `src/pixel-printing.js`, keep `src/pixel-printing.d.ts` in sync, run `npm test`, and check `index.html` (the GitHub Pages demo) and `examples/index.html` in a browser.
